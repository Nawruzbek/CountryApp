# Глоссарий

| Термин | Описание |
|--------|----------|
| **Country** | Страна — основная сущность, содержащая информацию о государстве (название, столица, население, площадь, валюта, глава) |
| **Region** | Регион — административная единица внутри страны (область, провинция, штат) |
| **Authentication** | Аутентификация — процесс проверки пользователя (логин и пароль) |
| **SQLite** | Легковесная реляционная база данных, используемая для хранения данных |
| **Controller** | Класс-контроллер, обрабатывающий бизнес-логику и взаимодействие с БД |
| **Interface** | Класс-интерфейс, отвечающий за ввод/вывод данных от пользователя |
| **Entity** | Класс-сущность, описывающий схему данных (Country, Region, User) |
| **ER-диаграмма** | Диаграмма "сущность-связь", показывающая структуру базы данных |
| **Use Case** | Вариант использования — сценарий взаимодействия пользователя с системой |
| **SELECT** | SQL-запрос для выборки данных из базы |
| **DELETE** | SQL-запрос для удаления данных из базы |
| **CASCADE** | Каскадное удаление — автоматическое удаление связанных записей |
